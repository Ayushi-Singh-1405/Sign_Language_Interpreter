{\centerline { {\large \textbf{ABSTRACT}}}}
~\\

The Sign Language Interpreter is a real-time ASL (American Sign Language) gesture recognition system that bridges communication between deaf and hearing individuals. Using computer vision and machine learning, this system translates hand gestures into text and speech in real-time. The system captures live video from a standard webcam, detects hand landmarks using MediaPipe's pre-trained hand landmark detector, and recognizes all 26 ASL alphabets (A-Z) using a Random Forest classifier.

This report presents the complete development process from problem identification to implementation, including system architecture, feature extraction methodology, model training, and the user interface. The system provides text output with optional text-to-speech conversion, making it accessible for both deaf and hearing individuals to communicate seamlessly.
